# To-Do-List
This is a Python To-Do List application using EasyGUI. It is a project for students and general users who need to manage and keep track on homework, daily tasks or shopping list. It allows users to create, load, and manage multiple task lists. Tasks will be saved to text files so they can be loaded later.


To run the program, open ToDoList-Version3.py and make sure Python and EasyGUI are installed.

Installation
Make sure you have Python 3 installed on your computer.
You can download it from: https://www.python.org/

Install EasyGUI by opening Command Prompt / Terminal and type in:
pip install easygui


How to run the program:
Open the project folder
Run ToDoList-Version3.py using Python
Follow the EasyGUI window menu to use the program


Features include creating lists, adding and deleting tasks, marking tasks as completed, and saving progress.
